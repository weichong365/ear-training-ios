1登录 App Store Connect

打开 appstoreconnect.apple.com，用你的 Apple ID 登录（与 Apple Developer 账号一致）。

首次登录需要同意协议。在「协议」标签页确认所有协议已签署（Developmental Agreement 等）。

如果某个协议没签，「我的 App」会锁定无法创建 App。签完所有协议后等 5–10 分钟刷新。

4填 App 隐私（App Privacy）

左侧栏点「App 隐私」标签页 → 点「开始」回答问题。

本版本不收集任何数据，所有答案都选「否」：

  • 你或你的 App 是否会从该 App 收集任何数据？否
  • 所有后续问题（联系信息、健康健身、财务信息、位置、敏感信息、联系人、使用数据、诊断、购买、用户内容、浏览历史、标识符、搜索）全部选「否」
选完后页面顶部会显示「Data Not Collected」绿色徽章。发布后 App Store 会显示「No Data Collected」标签。
App 内不收集数据 + 隐私政策已声明 + 隐私标签选 No Data Collected = 三处一致。审核员最关注这一致性。

6等构建上传后选构建 + 提交审核

这一节在你升级 EAS 套餐（$19/月 Starter）或等 10/1 免费额度恢复后，告诉我「已升级」或「额度恢复了」之后执行。我会触发 EAS 构建命令：

cd "F:\WorkBuddy\练耳大师\ios-app" && \ unset http_proxy https_proxy HTTP_PROXY HTTPS_PROXY all_proxy ALL_PROXY && \ npx eas-cli build --platform ios --profile production --non-interactive --auto-submit --no-wait

EAS 构建约 10–20 分钟。成功后会自动把 .ipa 上传到 App Store Connect 的「构建」列表。

6.1 选构建

回到 App Store Connect → 「我的 App」→ 练耳搭子 → 「1.0.0」→ 滚到「构建」区域 → 选中刚上传的构建（看 buildNumber = 36 或更新的那个）→ 点「完成」。

6.2 选版本发布方式

  • 自动发布此版本（审核通过后立即上架）—— 推荐首版
  • 手动发布此版本（审核通过后你手动点发布）

6.3 提交审核

滚到「构建」下面，点右上角「添加以供审核」→ 弹窗确认 → 选「提交以供审核」。

首次提交会要求再次确认出口合规（用了 usesNonExemptEncryption=false，选「是，使用豁免加密」即可，因为 App 不含任何加密功能）。

6.4 等待审核结果

通常 24–48 小时内出结果。可在 App Store Connect →「活动」查看进度。如果被打回，会有邮件 + 后台红色提示，给出具体原因，我们针对性修复后再提交。

7常见被打回原因 + 应对

5.1.1 隐私问题

原因：隐私标签和数据收集不一致，或隐私政策 URL 无法访问。

应对：确保「App 隐私选 No Data Collected」+「隐私政策 URL 实际可打开」+「App 内不收集数据」三处一致。

2.1 截图与 App 不符

原因：截图展示了 App 没有的功能。

应对：5 张截图都基于真实 iOS 界面设计，1:1 还原，可放心。

4.0 重复 App

原因：被认为和已有 App 重复。

应对：练耳搭子定位「音乐艺考视唱练耳」，垂直细分领域，不冲突。

Guideline 2.3 - 隐藏或伪装功能

原因：App 里有功能入口但不可用，或故意隐藏订阅等。

应对：首版纯免费，App 内无任何「订阅」「购买」入口（已清理干净）。

如果被打回，不要慌。把 App Review 的反馈原文发给我，我帮你分析原因并修复代码，48 小时内可重新提交。
