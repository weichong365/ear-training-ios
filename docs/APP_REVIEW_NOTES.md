# App Review 审核说明（1.0.1 免费首发版）

## 测试路径

App 不要求注册或登录，也没有隐藏的账号权限。1.0.1 首发版全部核心功能免费开放，订阅功能已关闭，审核人员无需演示账号或沙盒购买即可测试完整流程。

1. 首次启动选择省份，进入与该省统考框架对应的首页训练模块。
2. 从首页进入任意“专项训练”，点击绿色播放按钮；音频开始时答题谱面立即解锁。
3. 播放尚未结束时，播放按钮保持锁定；播放完整结束后才可再次播放。
4. 在五线谱上写入音符，或选择拍号、调号和时值完成节奏/旋律写谱。
5. 从首页进入“模拟考试”，开始试卷；退出后重新进入可继续本机保存的进度。
6. 交卷后显示总分、逐题得分和正确答案。

## 音频说明

- App 只播放随 App 分发的钢琴采样，不请求麦克风权限。
- 音频在 iPhone 静音模式下仍可播放，这是练耳核心功能所必需。
- App 不在后台持续播放音频。
- 和弦内各音使用完全相同的起始采样帧，确保同时发音。

## 数据与隐私

- 当前版本不接入广告、第三方分析、跨应用追踪或微信登录。
- 练习记录、错题、统计和未完成试卷默认存储在设备本地。
- 1.0.1 免费首发版不会初始化或调用 RevenueCat，也不会上传订阅或购买数据。
- 用户可以在“关于练耳搭子”中清除全部本机练习数据。
- 当前版本没有用户账号，因此没有账号删除流程。

## 商业模式

1.0.1 为免费首发版，不提供 App 内购买、自动续订、外部支付或邀请码解锁。未来若启用订阅，将在新版本中同步更新 App Privacy、隐私政策和审核说明，并单独提交相关商品审核。
