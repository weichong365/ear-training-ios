### 4.1 App Privacy 隐私标签（App Store Connect 填写用）

按最终 SDK 实际情况填写：

| 数据类型 | 是否收集 | 用途 | 关联到用户 |
|---------|---------|------|-----------|
| **购买信息** | 是 | App 功能（订阅验证） | 是 |
| **用户标识符** | 是 | App 功能（RevenueCat 匿名 App 用户 ID） | 是 |
| **使用数据** | 否 | —（本地保存，不上传） | — |
| **诊断数据** | 否 | — | — |
| **位置/联系人/健康/搜索/浏览历史** | 否 | — | — |

**追踪声明**：无跨 App 或网站追踪（不填 App Tracking Transparency）。
