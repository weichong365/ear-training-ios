## ③ 真机验收（精简版，完整版见 docs/TESTFLIGHT_TEST_PLAN.md）

**必测（阻断级）：**
- [ ] 静音开关开启时，练耳音频仍能播放（这是核心功能，已在审核备注声明）
- [ ] 播放中切后台/锁屏再返回，不崩溃、音频不卡死
- [ ] 来电/耳机拔插后音频能恢复
- [ ] 连续点击播放按钮不会消耗多次机会或叠放两段音频
- [ ] 和弦三音同时起音（无琶音感）
- [ ] 免费首发：无需登录、购买或兑换码即可进入全部核心训练
- [ ] 模拟考试：任一省份能建卷、退出恢复进度、交卷计分正确

**选测：** 蓝牙耳机、飞行模式、低电量、字体放大、深色模式。
