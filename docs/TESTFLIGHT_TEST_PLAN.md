# TestFlight 真机验收计划

## 必测设备状态

- iPhone 静音开关开启/关闭
- 扬声器、蓝牙耳机和有线耳机
- 来电或其他 App 抢占音频后返回
- 播放中锁屏、切后台、回到前台
- 飞行模式和无网络环境
- 低电量模式、字体放大和深色系统设置

## 训练流程

- 首次启动必须先选择省份；重启后保留选择，首页可随时切换
- 按当前省份出现的全部专项各完成至少 10 题（含音组、和声音程连接、和弦性质/音高等省份特有入口）
- 播放中连续点击不会增加次数或启动第二段音频
- 标准音/预备拍一开始，答题区就能写入
- 单音、音组、音程和和弦的答题音符默认为全音符
- 全音符在线上时，谱线穿过符头中心
- 任意抽查 20 题：音频、绿色标准谱面、答案文字和钢琴高亮必须是同一音高
- G 大调升号位于五线，F 大调降号位于三线
- 音符不与谱号、调号、拍号和小节线重叠
- 和弦三个音听感同时起音
- 标准音播放时复盘键盘 A4 显示黄色，答案开始后切换为绿色
- 复盘钢琴 G3–B3 五个琴键音高各不相同，C4–A5 与题目采样一致
- 音量可调到 0%，退出后重新进入仍保留，并同时用于模拟考试
- 智能强化至少覆盖五种题型，且历史错率较高题型出现比例更高

## 模拟考试

- 31 个省级入口均能生成试卷；16 个专属框架显示真实年份，其余使用全国通用框架
- 至少抽查一个专属省份和一个通用框架省份的完整交卷流程
- 多年份省份可以切换年份
- 浙江选择卷每题均为四个不同选项
- 山东和弦性质选项可以选择和切换
- 节奏/旋律拍号、调号不会在未作答时预填
- 退出后恢复答案、播放次数和当前题号
- 未答完交卷会提醒，交卷分数和逐题复盘正确
- 交卷成绩进入统计；模拟考试错题只在交卷后的原卷面复盘，不写入专项错题本

## 免费首发版

- 首次启动无需登录、购买或兑换码
- 所有首页训练模块和模拟考试均可直接进入
- 不显示订阅价格、免费试用、恢复购买或订阅管理入口
- 断网后仍可进入已内置的全部核心训练
- 无网络时显示可重试提示，不出现永久读取中状态

## 数据

- 清除本机数据会同时删除练习、错题、考试进度和考试成绩
- 升级构建后旧数据不会导致崩溃
- 卸载重装后本机数据消失

任何音频不同步、写谱重叠、崩溃、黑屏或无法恢复进度的问题都应视为阻断发布。
