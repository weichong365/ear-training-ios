# TestFlight 真机验收计划

## 必测设备状态

- iPhone 静音开关开启/关闭
- 扬声器、蓝牙耳机和有线耳机
- 来电或其他 App 抢占音频后返回
- 播放中锁屏、切后台、回到前台
- 飞行模式和无网络环境
- 低电量模式、字体放大和深色系统设置

## 训练流程

- 五种专项各完成至少 10 题
- 播放中连续点击不会增加次数或启动第二段音频
- 标准音/预备拍一开始，答题区就能写入
- 全音符在线上时，谱线穿过符头中心
- G 大调升号位于五线，F 大调降号位于三线
- 音符不与谱号、调号、拍号和小节线重叠
- 和弦三个音听感同时起音
- 标准音播放时复盘键盘 A4 显示黄色，答案开始后切换为绿色
- 复盘钢琴 G3–B3 五个琴键音高各不相同，C4–A5 与题目采样一致
- 音量可调到 0%，退出后重新进入仍保留，并同时用于模拟考试
- 智能强化至少覆盖五种题型，且历史错率较高题型出现比例更高

## 模拟考试

- 14 个已录入真题资料的省份均能生成试卷
- 多年份省份可以切换年份
- 浙江选择卷每题均为四个不同选项
- 山东和弦性质选项可以选择和切换
- 节奏/旋律拍号、调号不会在未作答时预填
- 退出后恢复答案、播放次数和当前题号
- 未答完交卷会提醒，交卷分数和逐题复盘正确
- 交卷成绩进入统计；模拟考试错题只在交卷后的原卷面复盘，不写入专项错题本

## 订阅

- 月度、年度方案显示 App Store 本地价格与 7 天免费试用资格
- 购买成功后立即解锁，不需要重启 App
- 取消购买不会误显示错误或解锁
- “恢复购买”可恢复同一 Apple ID 的有效权益
- “管理 Apple 订阅”可打开系统订阅管理
- 无网络时显示可重试提示，不出现永久读取中状态

## 数据

- 清除本机数据会同时删除练习、错题、考试进度和考试成绩
- 升级构建后旧数据不会导致崩溃
- 卸载重装后本机数据消失

任何音频不同步、写谱重叠、崩溃、黑屏或无法恢复进度的问题都应视为阻断发布。
