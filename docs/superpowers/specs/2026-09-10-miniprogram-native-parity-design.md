# 小程序优化同步至 iOS App：原生一致性设计

## 目标

把本轮小程序中已经确认的视觉、谱面、音频和流程优化同步到现有 Expo/React Native iOS App。同步的是产品结果与视觉意图，而不是微信小程序的实现细节；App 继续遵守 iOS 的安全区、动态字体、原生导航、辅助功能和 Apple 订阅规则。

## 原则

1. 题库、答案、评分、谱面语义和音频资产必须与小程序一致。
2. 相同页面保持相同信息层级、品牌颜色、图标语义和尺寸关系。
3. iOS 使用 React Native、React Native SVG、Expo Audio 和 Expo Router 的原生能力，不复制 WXML/WXSS 或微信胶囊导航。
4. 优先扩展现有组件和共享核心，不新建平行实现，不增加依赖。
5. 保留当前 Apple 内购、系统返回手势、安全区和无障碍行为。

## 同步范围

### 首页

- 英雄卡采用小程序最终确认的 C 方案：现有墨绿品牌面、底部克制波形、数据区渐隐细分割线；波形不得伸入数据文字。
- 会员状态条保持白色容器，绿色“你是月/年会员”区域右侧内边距与左侧会员说明一致，不越出容器。
- 八个训练入口使用同一套可爱手绘线性图标：单音空心符头、三音音组、音程、纵向相贴全音符和弦、节奏、高音谱号、模拟考试、智能强化；统一视觉尺寸并在底色块中居中。
- 首页高音谱号图标独立于五线谱高音谱号素材。
- 底部四个导航图标统一视觉尺寸；首页耳机罩为实心，错题图标简化，“我的”两条横线不与人体粘连，“举手”使用平滑矢量轮廓。

- 不把微信右上角胶囊移植到 App。

### 谱面与作答

- 所有谱面元素从统一谱线坐标推导：音符、临时记号、谱号、休止符、调号、拍号、小节线、结束线和空态提示。
- 升号相对原尺寸缩小 10%。
- 上下加线遵守标准线距，线宽与五线一致；全音符左右居中于加线。
- iOS/安卓小程序已确认的音符垂直锚点规则映射到 App 的 SVG 坐标，不使用字体基线定位。
- 朝上、朝下符干都必须与符头重叠连接，符干端点由符头几何统一计算。
- 小节线和结束线严格位于第五线中心到第一线中心之间，不越出外侧谱线。
- “播放题目后开始作答”等空态文字居中于五线谱可视区域。

### 音频与复盘钢琴

- App 使用与小程序字节一致的 G3–A5 共 27 个钢琴采样。
- 音高按 A4=440Hz 十二平均律校准，允许的自动检测误差不超过 ±0.5 音分。
- 单音题和复盘钢琴实际输出 1.85 秒（1.77 秒持续 + 0.08 秒渐隐）；旋律、节奏继续遵守谱面时值。
- 题目与复盘钢琴使用同一采样和渲染包络。精确采样不启用不必要的运行时变速处理。
- 播放失败只显示用户可理解且可恢复的提示，不在界面显示底层错误字符串。

### 练习与错题

- 复盘钢琴锁定层及图标在琴键区域水平、垂直居中；锁孔方向与最终小程序视觉一致。
- 复盘钢琴仅在提交答案后解锁，回放期间避免按键音与题目音频叠加。
- 错题分类默认闭合，用户主动展开后才显示题目列表。

### 省份、会员与说明

- 省份选择页页眉使用 App 统一导航颜色与安全区处理。
- 会员状态条与首页其他卡片对齐。
- 续费说明使用“续费后剩余天数会从当前剩余天数往上叠加。”；说明文字不使用独立底色块。
- App 继续使用 Apple 订阅与续期说明；不移植小程序支付实现。

### 模拟考试

- 江苏卷旋律音程性质选项使用明确的最小高度、边框盒和垂直居中，第二行下边缘不得裁切。
- 从首页进入模拟考试时，先解析已选省份再显示内容；已有省份时直接显示对应考试配置，不闪现省份选择界面。
- 省份框架、选择卷生成、答案和评分继续由现有同源核心提供。

## 实现边界

- 复用并收敛 `src/core/music-notation.ts`、谱面组件和音频服务中的公共几何与播放规则。
- 视觉调整集中在现有首页、练习、错题、省份、订阅和模拟考试页面，不创建第二套主题系统。
- 手绘图标用现有 SVG/矢量组件实现，保持清晰缩放与统一笔画；不增加位图图标依赖。
- 微信 JSAPI 权限错误、微信胶囊导航、Codemagic 配置和小程序包体限制不属于 App 同步范围。

## 状态与错误处理

- 省份上下文未加载完成时显示稳定的页面占位，不显示错误的中间页面。
- 音频准备、播放、回放和复盘钢琴保持互斥；可恢复错误允许用户再次操作。
- 页面离开时停止音频与定时任务；返回后不泄露技术诊断文字。
- 会员与试用状态沿用 App 当前本地持久化和 StoreKit 数据，不读取小程序状态。

## 验证

1. 扩展同源检查，覆盖题库、答案、评分、省份框架、选择卷、PCM 渲染器和 27 个钢琴采样。
2. 扩展 App smoke checks，覆盖加线、符干连接、小节线边界、图标状态、错题默认闭合、音频时长及无运行时变速。
3. 运行 TypeScript/Expo 项目检查及现有完整测试。
4. 在项目支持的 iPhone 模拟器上进行一次集中视觉验收：主页、练习答题与反馈、错题、省份、会员、江苏模拟考试。
5. 视觉验收只进行一轮集中修正和一轮确认，避免无边界反复抛光；真机音色与触感仍需用户最终确认。

## 完成标准

- 本文列出的所有可移植优化均在 App 中可见或可测。
- App 与小程序共享核心和钢琴资产检查通过。
- 关键页面无裁切、闪屏、错位、错误文本泄露或不可恢复状态。
- 未改变 Apple 订阅规则、省份题型规则、评分规则和现有用户数据格式。
